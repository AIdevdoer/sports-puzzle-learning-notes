# Sports Puzzle Learning Notes

This small reference collects repeatable practice methods for sports guessing games. Each method asks the player to write a reason before making a guess.

## NFL player clues

Start with position, then conference, team identity, and career history. Use the daily [NFL Wordle player puzzle](https://wordlecup.today/en/nfl/) to test whether each clue actually reduces the shortlist.

## Football logo recall

Separate shape, color, lettering, and regional symbols. The [football logo memory game](https://wordlecup.today/en/football/) provides a short recall round for these visual cues.

## Basketball player profiles

Group clues by position, era, franchise, and nationality. The [basketball player puzzle](https://wordlecup.today/en/basketball-wordle/) gives six attempts to apply the worksheet.

## Review routine

1. Record the first two candidates.
2. Cross out a candidate only when a later clue conflicts.
3. Note the clue that changed the shortlist most.
4. Save one error as the next review cue.

The repository also includes a rendered HTML note and a Jupyter notebook version of this routine.
